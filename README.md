# FARSTAR Panel

پنل مدیریت Xray با ظاهر مینیمال، سهمیهٔ مشترک بین اینباندها و فروش VPN در تلگرام.
این پروژه بر پایهٔ سورس کامل [3x-ui ثنایی](https://github.com/MHSanaei/3x-ui) ساخته شده؛ نسخهٔ نمایشی قدیمی در `design-prototype/` آرشیو شده و پنل واقعی نیست.

## نصب آسان روی لینوکس

با کاربر root وارد سرور شوید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/farstar-team/panel/main/install.sh)
```

نصاب مثل 3x-ui پورت، حساب مدیریت و مسیر ورود را تنظیم می‌کند، فایل انتشار را دریافت و SHA256 آن را بررسی می‌کند. اطلاعات ورود را امن نگه دارید. نام سرویس و فرمان مدیریت برای سازگاری `x-ui` باقی مانده است.

```bash
x-ui
x-ui status
x-ui restart
```

از HTTPS معتبر یا اتصال SSH استفاده کنید؛ پنل مدیریت را با HTTP باز روی اینترنت استفاده نکنید. قبل از ارتقای پنل موجود، از پایگاه‌داده و تنظیمات پشتیبان بگیرید.

## قابلیت‌های اضافه‌شده

- طراحی ساده با فضای سفید، رنگ سبز ملایم، حالت روشن/تیره و پشتیبانی فارسی و راست‌به‌چپ.
- ساخت نوع کانفیگ در «اینباندها»؛ بدون تب جداگانهٔ سابسکرایب در منوی اصلی.
- انتخاب پیش‌فرض اینباندهای فعال هنگام ساخت کاربر و نمایش خودکار لینک و QR اشتراک بعد از ذخیره.
- ضریب مصرف مستقل برای هر اینباند، پیش‌فرض ۱؛ مثلاً مصرف ۱ گیگابایت از اینباند ضریب ۲، سهمیهٔ کاربر را ۲ گیگابایت کم می‌کند.
- فروشگاه تلگرام: پلن، خرید، رسید، تأیید یا رد مدیر، تحویل خودکار اشتراک و QR، تمدید، پیگیری سفارش و پشتیبانی.
- سفارش‌های ماندگار و جلوگیری از تحویل/تمدید دوباره با تکرار تأیید.

## پایهٔ پروژه و محدودیت‌ها

سورس کامل 3x-ui در commit `99047c0a6394af4f74a3105220f2910ef615dce8` حفظ شده است: پروتکل‌ها، مدیریت کاربران، نودها، تنظیمات Xray، Routing، API، پشتیبان‌گیری، اعلان‌ها و ابزارهای اصلی حذف نشده‌اند. حفظ سورس به معنی تست همهٔ ترکیب‌های ممکن نیست.

ضریب مصرف از آمار واقعی هر اتصال در Xray محاسبه می‌شود و سهمیهٔ کاربر مشترک است؛ آمار اینباند همچنان مصرف خام شبکه را نشان می‌دهد. برای نودهای راه‌دور، FARSTAR را روی نود هم نصب کنید؛ نسخهٔ اصلی 3x-ui این فیلد را نمی‌شناسد. TUIC در سورس پایه فقط آمار تجمیعی اینباند دارد؛ محاسبهٔ ضریب سهمیهٔ هر کاربر برای TUIC پشتیبانی نمی‌شود. هزینهٔ شبکه، هدرها و گردکردن بایت می‌تواند باعث تفاوت با عدد برنامهٔ مشتری شود.

درگاه آنلاین و Telegram Stars در این نسخه پیاده نشده‌اند. پرداخت با رسید، تنها پس از تأیید واقعی مدیر فعال می‌شود. ربات برای کارکرد زنده به توکن BotFather و شناسهٔ عددی مدیر نیاز دارد.

## توسعه

Go و Node مطابق `go.mod` و `.nvmrc`، به همراه کامپایلر C لازم‌اند:

```bash
cd frontend
npm ci
npm run gen
npm run typecheck
npm run build
cd ..
go build -o x-ui .
```

برای بررسی کامل از `make verify` استفاده کنید. بسته‌های آماده و checksum در [Releases](https://github.com/farstar-team/panel/releases) منتشر می‌شوند.
